# @cosmicdrift/kumiko-dev-server

Dev tooling for Kumiko apps: local dev server (`runDevApp`), scaffolding and codegen, plus the `kumiko-*` build and schema commands.

## Install

```bash
bun add @cosmicdrift/kumiko-dev-server
```

```ts
import { runDevApp } from "@cosmicdrift/kumiko-dev-server";
```

Bun is required for the bundled commands.

Documentation: https://kumiko.rocks
